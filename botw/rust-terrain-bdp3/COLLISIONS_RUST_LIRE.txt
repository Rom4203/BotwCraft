BotwCraft / collisions SkyCraft alimentées par Zelda Havok
==========================================================

LE SOL DE ZELDA EST LU DANS ZELDA, ET NON DEPUIS DES .hght.

- Module Zelda WiiXLaunch : 9 raycasts Havok autour de Link.
- Bridge Windows : Rust transforme ces raycasts en triangles et sous-voxels.
- Mod Minecraft SkyCraft 0.1.2 : les triangles freinent Steve et le serveur
  Minecraft intégré voit le même terrain via les sous-voxels.
- La caméra et les entrées de BDP3 sont conservées ; aucun second JAR,
  faux serveur Minecraft, pilote virtuel ni téléportation en boucle.

Installation : INSTALLER_COLLISIONS.bat
Démarrage : START_BOTWCRAFT.bat
Dans Minecraft : /botwcraft connect puis /botwcraft inputs on

Surveiller logs/botwcraft.log :
  [BOTW_NATIVE] TERRAIN_HAVOK_FIRST_GROUND_HIT
  [TERRAIN] Havok surface seq=... triangles=... solid_blocks=...
Si triangles=0, aucune collision Zelda n'est encore disponible.

ATTENTION : jeu réel non vérifié dans cet environnement. Les raycasts
reposent sur les adresses NX150 BOTW 1.5.0 et peuvent échouer ou crasher
Ryujinx si les symboles ou structures Havok diffèrent. Tester sur des
sauvegardes temporaires ; les surfaces verticales et constructions ne sont
pas encore toutes couvertes par cette grille de sols 3x3.

Compilation Rust et module Switch : GitHub Actions (branche
botw-rust-native-collisions) : tests et build réussis.
